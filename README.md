# Formation consultant technique SAP

## Parcours

1. `001 - DEVELOPPEMENT ABAP SOCLE` : syntaxe, données, tables internes, Open SQL et reports.
2. `002 - DEVELOPPEMENT ABAP OBJECT` : modules fonction, objets ABAP et techniques associées.
3. `003 - QUALITY & UNIT TESTS` : contrôles statiques, tests et traces.
4. `004 - SEGW GATEWAY & ODATA BACKEND` : création, exposition, implémentation et diagnostic d'un service OData V2 avec SAP Gateway.
5. `005 - FIORI` : structure et développement d'une application SAPUI5/Fiori consommant un service OData.

## Règle d'utilisation

Suivre les blocs dans l'ordre. Dans chaque dossier, commencer par `00 - SOMMAIRE`, exécuter les exemples dans un système de formation, puis réaliser l'auto-évaluation. Les noms commençant par `Z`, les identifiants, les services et les données affichées sont des exemples à adapter au système utilisé.
