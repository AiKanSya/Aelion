# 🌸 SOMMAIRE — └─ 🧩 01 - BASIC

## 🌺 OBJECTIF DU PARCOURS

Ces exercices révisent la création et l’organisation des premiers objets ABAP dans SAP GUI :

1. ordre de transport ;
2. package transportable ;
3. programme exécutable ;
4. includes ;
5. dump et débogueur ;
6. intégration collective dans un ordre de transport.

Les exercices sont progressifs. Les objets créés dans un exercice sont réutilisés dans les suivants.

## 🌺 RÈGLES COMMUNES

- Remplacer `<TRI>` par le trigramme attribué.
- Utiliser uniquement le système de développement prévu pour la formation.
- Ne pas libérer une tâche ou un ordre de transport sans consigne explicite du formateur.
- Enregistrer les objets dans le package et l’ordre de transport demandés.
- Activer les objets avant leur exécution.
- Lire la solution uniquement après un premier essai autonome.
- Conserver une preuve de réalisation : identifiant, capture, code ou résultat d’exécution.

> [!IMPORTANT]
> Si un objet portant le même nom existe déjà, ne pas le modifier. Utiliser le suffixe communiqué par le formateur.
