### Solution — définitions

| Notion         | Définition                                                                        |
| -------------- | --------------------------------------------------------------------------------- |
| `SE16N`        | Transaction de consultation et d’analyse du contenu de tables ou vues autorisées. |
| Table          | Objet contenant des enregistrements structurés en base de données.                |
| Vue            | Objet logique exposant des champs provenant d’une ou plusieurs sources.           |
| Champ          | Composant typé d’une ligne.                                                       |
| Enregistrement | Ligne de données.                                                                 |
| Clé primaire   | Ensemble de champs identifiant une ligne de manière unique dans une table.        |
| Critère        | Condition appliquée avant la lecture des données.                                 |
| Nombre maximal | Limite du nombre de lignes retournées ou affichées par la sélection.              |
| Grille ALV     | Présentation tabulaire interactive du résultat.                                   |
| Export         | Création d’un fichier à partir des lignes et colonnes affichées.                  |
