# 🌸 EXERCICES — DO ENDDO - CONTROLE DES BOUCLES EN ABAP

## 🌺 OBJECTIFS

À la fin de l’exercice, le stagiaire doit être capable de :

- exécuter un bloc un nombre déterminé de fois ;
- utiliser `sy-index` ;
- utiliser une limite dynamique ;
- filtrer des itérations avec `CHECK` ;
- sauter une itération avec `CONTINUE` ;
- quitter une boucle avec `EXIT` ;
- prévoir précisément le résultat d’une boucle ;
- distinguer une boucle bornée d’une boucle sans limite explicite.

## 🌺 DURÉE INDICATIVE

50 à 65 minutes.

## 🌺 EXERCICE 1 — RESTITUTION

Compléter le tableau suivant :

| Élément            | Rôle |
| ------------------ | ---- |
| `DO 5 TIMES.`      |      |
| `DO.`              |      |
| `ENDDO.`           |      |
| `sy-index`         |      |
| `CHECK condition.` |      |
| `CONTINUE.`        |      |
| `EXIT.`            |      |

Répondre ensuite aux questions :

1. Quelle valeur possède `sy-index` lors du premier passage ?
2. Une boucle `DO 5 TIMES` a-t-elle besoin d’un `EXIT` pour se terminer ?
3. Une boucle `DO.` sans limite explicite est-elle nécessairement infinie ?
4. Quelle condition doit être remplie pour qu’une boucle `DO.` reste maîtrisée ?
5. `CONTINUE` quitte-t-il la boucle entière ?

## 🌺 EXERCICE 2 — BOUCLE FIXE ET TABLEAU DE TRACE

Afficher les nombres de `1` à `5` ainsi que leur carré.

Résultat attendu :

```text
Itération 1 - Carré 1
Itération 2 - Carré 4
Itération 3 - Carré 9
Itération 4 - Carré 16
Itération 5 - Carré 25
```

Avant d’exécuter, compléter le tableau :

| `sy-index` | Calcul  | Carré |
| ---------: | ------- | ----: |
|          1 | `1 * 1` |       |
|          2 | `2 * 2` |       |
|          3 | `3 * 3` |       |
|          4 | `4 * 4` |       |
|          5 | `5 * 5` |       |

Contraintes :

- utiliser `DO 5 TIMES` ;
- ne pas créer de compteur manuel ;
- calculer le carré dans une variable ;
- afficher une ligne par passage.

## 🌺 EXERCICE 3 — NOMBRE D’ITÉRATIONS DYNAMIQUE

## 🌺 EXERCICE 6 — SORTIE AVEC EXIT

## 🌺 EXERCICE 7 — COMBINAISON

Parcourir au maximum `20` passages.

Règles :

1. ignorer les valeurs inférieures à `5` avec `CHECK` ;
2. ignorer les nombres pairs avec `CONTINUE` ;
3. quitter la boucle lorsque `sy-index` est supérieur à `13` ;
4. afficher les autres valeurs.

Résultat attendu :

```text
5
7
9
11
13
```

Compléter le tableau avant exécution :

| Valeur | `CHECK >= 5` | Pair | `> 13` | Action         |
| -----: | ------------ | ---- | ------ | -------------- |
|      3 | Faux         | —    | —      | passage ignoré |
|      5 | Vrai         | Non  | Non    |                |
|      6 | Vrai         | Oui  | Non    |                |
|     13 | Vrai         | Non  | Non    |                |
|     14 | Vrai         | Oui  | Oui    |                |

> [!IMPORTANT]
> L’ordre des contrôles influence le chemin réellement suivi.  
> Dans la solution, la condition de sortie est placée avant le filtrage des nombres pairs afin que la sortie soit évaluée dès que la limite est dépassée.

## 🌺 EXERCICE 8 — DIAGNOSTIC

Analyser :

```abap
DO 10 TIMES.

  IF sy-index = 5.
    EXIT.
  ENDIF.

  WRITE / sy-index.

ENDDO.
```

Répondre :

1. Quelles valeurs sont affichées ?
2. La valeur `5` est-elle affichée ?
3. Combien de passages commencent réellement ?
4. Quelle instruction faut-il utiliser pour ignorer uniquement `5` tout en poursuivant jusqu’à `10` ?
5. Corriger le programme.

### Solution — restitution

| Élément            | Rôle                                                                   |
| ------------------ | ---------------------------------------------------------------------- |
| `DO 5 TIMES.`      | Exécute le bloc cinq fois.                                             |
| `DO.`              | Démarre une boucle sans nombre de passages fixé par cette instruction. |
| `ENDDO.`           | Ferme le bloc de boucle.                                               |
| `sy-index`         | Contient le numéro du passage courant.                                 |
| `CHECK condition.` | Si la condition est fausse dans la boucle, passe au passage suivant.   |
| `CONTINUE.`        | Termine immédiatement le passage courant et démarre le suivant.        |
| `EXIT.`            | Termine la boucle et poursuit après `ENDDO`.                           |

1. `1`.
2. Non. La limite `5 TIMES` assure sa terminaison.
3. Non, à condition qu’un chemin exécutable atteigne une instruction de sortie.
4. Une condition de sortie doit devenir vraie après un nombre fini de passages.
5. Non. Il termine uniquement le passage courant.

### Solution — carrés

```abap
DATA lv_square TYPE i.

DO 5 TIMES.
  lv_square = sy-index * sy-index.

  WRITE: / 'Itération', sy-index,
           ' - Carré', lv_square.
ENDDO.
```

| `sy-index` | Calcul  | Carré |
| ---------: | ------- | ----: |
|          1 | `1 * 1` |     1 |
|          2 | `2 * 2` |     4 |
|          3 | `3 * 3` |     9 |
|          4 | `4 * 4` |    16 |
|          5 | `5 * 5` |    25 |

### Solution — limite dynamique

```abap
PARAMETERS p_times TYPE i DEFAULT 5.

START-OF-SELECTION.

  IF p_times NOT BETWEEN 1 AND 20.
    MESSAGE 'Le nombre de passages doit être compris entre 1 et 20'
      TYPE 'S'
      DISPLAY LIKE 'E'.
    RETURN.
  ENDIF.

  DO p_times TIMES.
    WRITE / sy-index.
  ENDDO.
```

### Solution — CHECK

```abap
DO 15 TIMES.
  CHECK sy-index MOD 3 = 0.
  WRITE / sy-index.
ENDDO.
```

| `sy-index` | Reste | `CHECK` | Affichage |
| ---------: | ----: | ------- | --------- |
|          1 |     1 | Faux    | Aucun     |
|          2 |     2 | Faux    | Aucun     |
|          3 |     0 | Vrai    | 3         |
|          4 |     1 | Faux    | Aucun     |
|          5 |     2 | Faux    | Aucun     |
|          6 |     0 | Vrai    | 6         |

### Solution — CONTINUE

```abap
DO 10 TIMES.

  IF sy-index = 4 OR sy-index = 7.
    CONTINUE.
  ENDIF.

  WRITE / sy-index.

ENDDO.
```

Le passage commence et `sy-index` prend sa valeur. `CONTINUE` empêche uniquement l’exécution des instructions restantes du passage courant.

### Solution — EXIT

```abap
DO.

  IF sy-index > 7.
    EXIT.
  ENDIF.

  WRITE / sy-index.

ENDDO.

WRITE / 'Après la boucle'.
```

### Solution — combinaison

```abap
DO 20 TIMES.

  CHECK sy-index >= 5.

  IF sy-index > 13.
    EXIT.
  ENDIF.

  IF sy-index MOD 2 = 0.
    CONTINUE.
  ENDIF.

  WRITE / sy-index.

ENDDO.
```

| Valeur | `CHECK >= 5` | Pair | `> 13` | Action            |
| -----: | ------------ | ---- | ------ | ----------------- |
|      3 | Faux         | —    | —      | passage suivant   |
|      5 | Vrai         | Non  | Non    | afficher          |
|      6 | Vrai         | Oui  | Non    | passage suivant   |
|     13 | Vrai         | Non  | Non    | afficher          |
|     14 | Vrai         | Oui  | Oui    | quitter la boucle |

### Solution — diagnostic

Valeurs affichées :

```text
1
2
3
4
```

Le cinquième passage commence, puis `EXIT` quitte la boucle avant l’affichage.

Correction :

```abap
DO 10 TIMES.

  IF sy-index = 5.
    CONTINUE.
  ENDIF.

  WRITE / sy-index.

ENDDO.
```
