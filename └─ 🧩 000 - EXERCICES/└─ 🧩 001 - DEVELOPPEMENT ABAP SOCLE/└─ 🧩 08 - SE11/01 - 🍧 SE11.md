# 🌸 EXERCICES — TRANSACTION SE11

## 🌺 OBJECTIFS

À la fin de l’exercice, le stagiaire doit être capable de :

- définir le rôle de `SE11` ;
- distinguer affichage, modification, contrôle et activation ;
- identifier les principales catégories d’objets ;
- naviguer entre un champ, son élément de données et son domaine ;
- utiliser les cas d’emploi ;
- visualiser les propriétés d’une table standard sans la modifier ;
- distinguer définition DDIC, objet d’exécution et contenu de table.

## 🌺 DURÉE INDICATIVE

40 à 55 minutes.

## 🌺 EXERCICE 2 — ANALYSE DE `MARA`

Dans `SE11`, afficher la table standard :

```text

```

Ne jamais passer en modification.

Relever :

- description ;
- premier champ clé ;
- champ mandant ;
- élément de données de `MATNR` ;
- domaine associé ;
- type technique et longueur visibles dans le système ;
- catégorie d’extension ;
- classe de livraison ;
- classe de données ;
- catégorie de taille ;
- mode de buffering ;
- présence éventuelle de structures append.

> [!IMPORTANT]
> Ne recopier aucune longueur depuis la mémoire.  
> Relever la définition réelle du système.

### Solution — restitution

| Notion            | Définition                                                                                     |
| ----------------- | ---------------------------------------------------------------------------------------------- |
| ABAP Dictionary   | Référentiel central des définitions de données globales et des objets de base de données ABAP. |
| `SE11`            | Transaction classique d’affichage et de maintenance des objets DDIC.                           |
| Version active    | Version utilisée à l’exécution.                                                                |
| Version inactive  | Modification sauvegardée mais non activée.                                                     |
| Contrôle          | Vérification de la cohérence de la définition.                                                 |
| Activation        | Génération et publication de la version utilisable.                                            |
| Cas d’emploi      | Liste des objets qui utilisent l’objet analysé.                                                |
| Objet d’exécution | Représentation générée utilisée par le runtime ABAP.                                           |
| Contenu           | Enregistrements stockés dans une table, distincts de sa définition.                            |

### Solution — relations

```text
MARA-MATNR
→ Élément de données MATNR
→ Domaine affiché dans le système
```

La valeur exacte du domaine, du type et de la longueur doit être relevée dans le système.

### Solution — stockage

| Objet                  | Catégorie                | Stockage physique propre                    |
| ---------------------- | ------------------------ | ------------------------------------------- |
| Domaine                | Type                     | Non                                         |
| Élément de données     | Type                     | Non                                         |
| Structure              | Type                     | Non                                         |
| Table transparente     | Objet de base de données | Oui                                         |
| Vue de base de données | Objet de base de données | Oui                                         |
| Aide à la recherche    | Aide à la saisie         | Non                                         |
| Objet de verrouillage  | Synchronisation          | Non ; il génère des modules de verrouillage |
