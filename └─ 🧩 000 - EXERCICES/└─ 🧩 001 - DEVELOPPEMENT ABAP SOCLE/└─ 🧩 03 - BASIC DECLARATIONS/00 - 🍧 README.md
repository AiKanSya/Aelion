# 🌸 SOMMAIRE — └─ 🧩 03 - BASIC DECLARATIONS

## 🌺 OBJECTIF DU PARCOURS

Ces exercices renforcent trois catégories de déclarations ABAP :

1. les variables ;
2. les constantes ;
3. les field-symbols.

Le stagiaire doit être capable de choisir une déclaration adaptée, d’identifier les risques liés au type d’une donnée et de distinguer un objet de données d’un alias vers une zone mémoire.

## 🌺 COURS ASSOCIÉS

- `03 - BASIC DECLARATIONS/01 - 🍧 VARIABLES.md`
- `03 - BASIC DECLARATIONS/02 - 🍧 CONSTANTS.md`
- `03 - BASIC DECLARATIONS/03 - 🍧 FIELD-SYMBOLS.md`

## 🌺 PROGRAMME UTILISÉ

Créer ou réutiliser le programme exécutable suivant :

```text
ZAELION_<TRI>_DECLARATIONS
```

Remplacer `<TRI>` par le trigramme attribué.

Le programme doit être enregistré dans le package et l’ordre de transport créés dans le dossier `01 - BASIC`.

## 🌺 RÈGLES COMMUNES

- Réaliser un premier essai sans ouvrir la solution.
- Utiliser la convention de nommage du cours :
  - `lv_` pour une variable locale élémentaire ;
  - `lc_` pour une constante locale ;
  - `<lfs_...>` pour un field-symbol local.
- Contrôler la syntaxe avant chaque activation.
- Exécuter chaque cas demandé.
- Conserver une preuve vérifiable : code, résultat ou explication structurée.
- Restaurer une version correcte après chaque erreur volontaire.
- Ne pas conserver de code provoquant une erreur de syntaxe ou d’exécution dans la version finale.

> [!IMPORTANT]
> Les préfixes utilisés sont des conventions de formation.  
> Ils ne constituent pas des mots-clés imposés par le langage ABAP.
