# 🌸 SOMMAIRE — └─ 🧩 02 - BASIC ABAP

## 🌺 OBJECTIF DU PARCOURS

Ces exercices renforcent trois notions fondamentales :

1. la structure événementielle d’un programme ABAP exécutable ;
2. l’utilisation pertinente des commentaires ;
3. la rédaction et la maintenance d’une cartouche technique.

Le programme `ZAELION_<TRI>_HELLOWORLD`, créé dans le dossier `01 - BASIC`, est réutilisé et complété progressivement.

## 🌺 COURS ASSOCIÉS

- `02 - BASIC ABAP/01 - 🍧 CODE STRUCTURE.md`
- `02 - BASIC ABAP/02 - 🍧 COMMENTS.md`
- `02 - BASIC ABAP/03 - 🍧 CARTOUCHE.md`

## 🌺 RÈGLES COMMUNES

- Remplacer `<TRI>` par le trigramme attribué.
- Remplacer les autres valeurs entre chevrons par les informations réelles.
- Utiliser le package et l’ordre de transport créés dans le dossier `01 - BASIC`.
- Enregistrer, contrôler la syntaxe et activer chaque objet modifié.
- Exécuter uniquement le programme principal, jamais un include.
- Réaliser un premier essai avant d’ouvrir la solution.
- Conserver une preuve vérifiable : code, capture, résultat ou explication.
- La version finale ne doit contenir aucune erreur volontaire.

> [!IMPORTANT]
> Les conventions de nommage et de cartouche peuvent varier selon le client.  
> Les conventions demandées dans ces exercices constituent le standard de la formation.
