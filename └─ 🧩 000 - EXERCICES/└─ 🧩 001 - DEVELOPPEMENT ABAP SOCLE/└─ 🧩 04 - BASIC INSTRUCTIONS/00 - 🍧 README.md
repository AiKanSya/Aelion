# 🌸 SOMMAIRE — └─ 🧩 04 - BASIC INSTRUCTIONS

## 🌺 OBJECTIF DU PARCOURS

Ces exercices permettent de réviser les instructions ABAP élémentaires utilisées pour :

1. afficher des données ;
2. informer l’utilisateur ;
3. effectuer des calculs ;
4. construire, nettoyer, découper, rechercher et modifier du texte ;
5. réinitialiser des données ;
6. extraire une sous-chaîne ;
7. convertir un texte vers un nombre sans provoquer de dump.

## 🌺 PROGRAMME UTILISÉ

Créer le programme exécutable suivant :

```text
ZAELION_<TRI>_INSTRUCTIONS
```

Remplacer `<TRI>` par le trigramme attribué.

Le programme doit être enregistré dans le package et l’ordre de transport utilisés pour les exercices précédents.

## 🌺 RÈGLES COMMUNES

- Réaliser un premier essai avant d’ouvrir la solution.
- Contrôler la syntaxe avant chaque activation.
- Exécuter chaque cas demandé.
- Comparer le résultat obtenu au résultat attendu.
- Restaurer une version correcte après chaque erreur volontaire.
- Ne pas conserver de code provoquant un dump ou une erreur de syntaxe.
- Conserver une preuve vérifiable : code, résultat ou explication structurée.
- Les résultats de dates, heures et nombres peuvent varier selon les paramètres utilisateur SAP.

> [!IMPORTANT]
> `WRITE` produit une liste classique. Cette instruction convient aux exercices de base et aux rapports simples, mais elle ne remplace pas un ALV ou une interface Fiori dans une application professionnelle.
